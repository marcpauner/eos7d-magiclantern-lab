Soup Engine film looks
======================

Develops each new CR2 into FLM_nnnn.JPG with a film look, using the
full-size JPEG preview Canon embeds in the raw. The raw sensor data is
never touched.

Shoot RAW (or RAW+JPEG) with a colour picture style. Looks are read from
ML/FILM on the card. Settings live on the Film (F) tab and in ML/SE.CFG.

"Rewrite CR2" (off by default) also puts the look into the CR2's own
preview, so playback shows it; that writes into the CR2 file.
