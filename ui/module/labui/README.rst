Lab UI
======

A redesigned menu for the EOS 7D: Ajustes, Superposiciones and Zebras,
with anti-aliased type, LED indicators and graduated rulers.

Trash opens it instead of the classic menu. Rear dial or joystick moves,
SET opens or toggles, the main dial and joystick left/right change values,
MENU goes back, Q opens the current setting in the classic menu.

Turn it off in Prefs > Lab UI to get the classic menu on Trash again.
